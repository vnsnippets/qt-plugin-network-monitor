### 🍚 What is this?
A Quickshell plugin that talks directly to **NetworkManager** over **DBus** without middleware, polling, regex hacks or external processes.

> Clean signals and properties exposed to QML

### 🔌 How it works?
- **One‑time reads (cold start):**  
  - `Connectivity` → fetched once at startup so you don’t begin at “Unknown.”  
  - `State` → fetched once at startup so you know the global NM state immediately.  

- **Reactive subscriptions (live updates):**  
  - `StateChanged` → fires when NM’s overall state changes (disconnected, connecting, connected).  
  - `PropertiesChanged` → fires when global properties like `Connectivity` change.  
  - `DeviceAdded` / `DeviceRemoved` → fires when devices appear/disappear.  
  - (Extendable: device state changes, active connection changes, settings changes.)

---

## 📡 Exposed Properties & Signals
- **Properties:**
  - `connectivityState` → integer 0–4
  - `globalState` → integer values like 10, 20, 40, 60, 70 (NM’s internal state machine)

- **Signals:**
  - `connectivityStateChanged()`  
  - `globalStateChanged()`  
  - `deviceAdded(QString path)`  
  - `deviceRemoved(QString path)`  
  - `deviceStateChanged(QString path, int state)`  
  - `activeConnectionStateChanged(QString path, int state)`  
  - `newConnection(QString path)`  
  - `connectionRemoved(QString path)`

---

## 🗒️ Cheat Sheet: Global State Values

| Value | Meaning                  |
|-------|--------------------------|
| 10    | Asleep (NM not managing) |
| 20    | Disconnected             |
| 30    | Disconnecting            |
| 40    | Connecting               |
| 50    | Connected (site only)    |
| 60    | Connected (local only)   |
| 70    | Connected (global)       |

*(Values may vary slightly depending on NM version, but these are the common ones.)*

## 🖥️ Sample QML Usage
```qml
import QtQuick
import NetworkManagerDBusPlugin

Item {
    NetworkMonitor {
        id: nm
        onConnectivityStateChanged: console.log("QML: Connectivity =", connectivityState)
        onGlobalStateChanged: console.log("QML: Global state =", globalState)
        onDeviceAdded: console.log("QML: Device added:", path)
        onDeviceRemoved: console.log("QML: Device removed:", path)
    }

    Column {
        anchors.centerIn: parent
        spacing: 10
        Text { text: "Connectivity: " + nm.connectivityState }
        Text { text: "Global State: " + nm.globalState }
    }
}
```
